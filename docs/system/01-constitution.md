# 宪法：本框架不可协商的规则

> 这是**规范自己的规范**。项目级的宪法由 `init` 生成在项目的 `.ai/constitution.md`，两者是不同层级的文档：
> 本文件约束框架的维护者（含 AI），项目宪法约束某个具体项目。

## 一、框架主张什么

1. **上下文是预算，不是免费资源。** 任何进入"每次会话都会加载"的文件都必须证明自己的价值。当前预算：`AGENTS.md` ≤ 150 行 / ≤ 2500 token；项目 `.ai/constitution.md` ≤ 150 行 / ≤ 1800 token。
2. **规范必须有触发时机。** 没有触发条件的规范一定会腐化。每个规范条目必须回答："什么时候会被读到、被什么动作更新？"
3. **规模先于复杂度。** 在决定架构之前先定规模等级（`docs/system/02-scales.md`）。小规模项目引入高级模式视为缺陷。
4. **索引必须可审计。** 让 AI 读什么文件，必须由一份落盘、可 diff、可复现的清单决定，而不是模型的自由探索或不可解释的检索。
5. **单一事实来源。** 同一知识只写一处。模板不复制规范正文，项目文档不复制框架规范正文，索引不复制源码逻辑（只写语义摘要）。
6. **一切自动可判定的东西都要自动判定。** 能写成 `review --drift` 检查的规则，绝不依赖"请记得"。

## 二、硬约束（改代码时不可违反）

| 约束 | 具体含义 | 违反后果 |
|---|---|---|
| 零依赖 | `cli/`、`scripts/`、模板中的脚本只允许 Node 内置模块 | 用户项目无法离线使用；供应链风险 |
| 跨平台 | 不使用 bash-only 语法；路径用 `node:path`；入口 `.mjs` | Windows 用户直接不可用 |
| 不猜变量 | 模板里的 `{{var}}` 必须已声明；渲染器对未知变量报错 | 生成带空占位符的项目，误导 AI |
| 阈值有出处 | 任何数字阈值必须能在 `docs/system/` 找到 | 无法判断何时该升级规模/预算 |
| 语言分层 | 用户文档中文；标识符、字段、路径、CLI 参数英文 | 代码与文档混语言，检索失效 |
| 幂等生成 | 同一输入重复 `init` 结果一致；已存在文件默认不动 | 覆盖用户代码 |

## 三、质量门槛（提交前必须全绿）

```bash
node scripts/validate.mjs   # 结构、模板变量、skill 引用、文档链接、token 预算
node scripts/selftest.mjs   # 端到端：每个模板包 init 到临时目录并跑全部命令
```

任一项失败即视为未完成。**不允许**通过放宽校验来让检查通过——那等于删除规则本身。

## 四、明确禁止

- 在框架中引入 npm 依赖（包括"只用一个"）。
- 用向量库/嵌入检索替代可审计的索引（理由见 `docs/04-design-notes.md`）。
- 让 CLI 自动改写用户源码或自动 `git commit`。
- 把规范正文复制进模板（应使用 `{{> SHARED:...}}`）。
- 为通过测试而降低断言强度、跳过用例、或让校验脚本忽略某类文件。
- 新建"看起来高级"的抽象层：未经 `docs/system/03-pattern-selection.md` 的规模门槛论证，不得引入设计模式。

## 五、宪法本身的修改

1. 修改本文件必须同时检查 `docs/system/09-change-protocol.md` 的影响矩阵。
2. 新增硬约束必须给出"违反后果"，并说明如何被自动检测（或为何不能）。
3. 删除规则必须记录在 `docs/05-changelog-of-rules.md`，写明删除理由与替代机制。
