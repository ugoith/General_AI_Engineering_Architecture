## 3. 环境变量

`.env.example` 是唯一权威清单：新增变量必须同时更新它，否则别人跑不起来。

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| (示例) `APP_PORT` | 是 | 8080 | 本地监听端口 |
| (示例) `DATABASE_URL` | 是 | 无 | 本地库连接串；不要写真实生产凭据 |
| (示例) `LOG_LEVEL` | 否 | info | debug 会输出敏感字段，只在本地用 |

## 6. 常见故障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 启动报缺少环境变量 | `.env` 未创建或变量名拼错 | 对照 `.env.example` 逐项核对 |
| 端口被占用 | 上一次进程没退出 | 结束占用进程或改 `APP_PORT` |
| 依赖安装后仍报找不到模块 | 锁文件与依赖目录不一致 | 删掉依赖目录后重新安装，不要手改锁文件 |
| 迁移报"已存在/不存在" | 本地库状态与迁移历史不一致 | 查看迁移历史，必要时重置本地库（仅本地） |
| 测试偶发失败 | 依赖了执行顺序或真实时间 | 定位共享状态；把它们写进本表 |

## 7. 排障原则

1. 先看日志与退出码，再猜原因；把关键输出贴进任务包"证据"。
2. 不要用"多加一个重试"掩盖问题；重试策略的改变属于公开行为变更。
3. 环境相关问题修好后，必须回写本手册（第 3 或第 6 节），否则下一个人还要重踩。
