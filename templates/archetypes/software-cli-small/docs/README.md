# 文档（S 级）

本规模（S / 轻量）**不要求架构文档**：一个人、一个模块、两千行以内的工具，靠根目录的 `README.md` + `.ai/constitution.md` + `{{aiDir}}/decisions/` 就能说清。

## 什么时候需要更多文档

满足任一条就该升级到 M 级：

- 出现第二个模块，或第二个长期使用者；
- 代码超过 2k 行，或需要多人并行改动；
- 预计寿命超过 3 个月，出现"上次为什么这么写"的争论。

升级动作：写一条"规模升级"ADR → 补 M 级要求的文档（架构概览、数据模型、接口、运维手册）→ 在 `.ai/constitution.md` 更新规模门槛一节。判定阈值与各级强制项见 `.ai/framework-docs/02-scales.md`。

## 本规模仍然必须记录的

- **决策**：影响后续选择的决定写进 `.ai/decisions/`，触发条件见 `AGENTS.md`。
- **变更**：用户可感知的变更写进 `CHANGELOG.md`。
- **验证**：能证明"做完了"的命令写进 `.ai/constitution.md` 的"验证命令"表（不要留在聊天记录里）。
