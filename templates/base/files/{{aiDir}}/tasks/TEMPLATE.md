# 任务包模板（structure reference）

> 任务包由 `node {{aiDir}}/bin/ai-arch.mjs task "<任务描述>"` 生成，写入 `{{aiDir}}/tasks/<日期>-<slug>.md`。
> 本文件是**结构说明 + 手工兜底模板**：字段与生成版一一对应，CLI 不可用时照此手写。
> 生成时已填好前三节；**开工前**补"范围 / 验收标准"，**收工前**补"结果 / 证据 / 遗留风险与假设"。没填完 = 任务未完成。

## 生成版的执行语义

| 标记 | 含义 | 你要做什么 |
|---|---|---|
| `read-source` | 摘要缺失、过期，或 hash 已变 | 打开源码读；读完用 `index --apply` 回写摘要 |
| `read-digest` | hash 未变且摘要存在 | **只读摘要，不要打开源码** |
| 因预算被丢弃 | 与任务相关但超出 `--budget` | 缩小任务范围，或提高 `--budget` 重生成 |
| `indexHealth` | 待写 / 过期摘要数量 | 先跑 `index --stale`，否则相关文件都会被判为"必须读源码" |
